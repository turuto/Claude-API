# Images for this exercise

Drop your own image file here (not committed — this folder should stay out of
git except for this README). The exercise looks for a base name of `satellite`,
trying `.jpg`, `.jpeg`, `.png`, `.gif`, and `.webp` in that order — the lesson's
fire-risk-assessment demo expects a satellite/aerial photo of a property with
some trees near the roofline, but any image works to see the prompt run.

Must be under 5MB (the API's per-image limit).
